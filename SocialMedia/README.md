# GNF SocialMedia

Static front-end mockup for the GNF social tasks and raffles flow.

## Preview Locally

```powershell
node server.mjs
```

Then open:

```text
http://127.0.0.1:4173/
```

## GitHub Pages

This project is static and can be hosted from the repository root with GitHub Pages.

Recommended Pages settings:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`
